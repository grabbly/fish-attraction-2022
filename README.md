# Fish Attraction (2022)

## Description
**Fish Attraction** is a children's fishing game featuring engaging rod-casting and fish-catching mechanics.

Developed in **Unity**, this project provides an entertaining and interactive underwater adventure where players can collect treasures and exchange them for decorative underwater items.

## Key Features
- **Fishing Mechanics** – Cast the rod, catch various fish, and explore different water areas.
- **Treasure Collection** – Discover and collect hidden underwater treasures.
- **Decoration System** – Exchange treasures for unique underwater decorations to personalize your aquatic world.
- **Kid-Friendly Design** – Simple and intuitive controls tailored for young players.

## Requirements
- **Unity** (version used for development: refer to project settings)
- Support for WebGL, Android, or iOS (depending on the platform)

## Installation & Running the Project
1. Clone the repository:
   ```sh
   git clone https://github.com/grabbly/fish-attraction-2022.git
   ```
2. Open the project in **Unity**.
3. Build the project for the desired platform or run it in the editor.
